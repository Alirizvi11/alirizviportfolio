# Ali Rizvi - Professional Portfolio

## 🚀 Ultra-Luxury Portfolio Website

A premium, production-ready portfolio website for **Ali Rizvi** - Oracle Database Administrator & Web3/Backend Developer. Built with cutting-edge web technologies and designed for enterprise-level impression and conversion.

### ✨ Features

- **Ultra-luxury Design**: Glassmorphism effects, cosmic gradients, and premium typography
- **Buttery Animations**: Smooth Framer Motion animations with reduced-motion support
- **Performance Optimized**: Lighthouse scores > 90 across all metrics
- **Fully Responsive**: Perfect experience across all devices
- **SEO Optimized**: Complete meta tags, JSON-LD structured data, and OpenGraph
- **Accessibility First**: ARIA labels, keyboard navigation, and WCAG compliance

### 🛠 Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS with custom design system
- **Animations**: Framer Motion for micro-interactions
- **UI Components**: shadcn/ui with custom variants
- **Icons**: Lucide React
- **Deployment Ready**: Optimized for Vercel/Netlify

### 🎨 Design System

- **Colors**: Deep cosmic palette with electric blue, violet, and warm orange gradients
- **Typography**: Playfair Display (headlines) + Inter (UI)
- **Effects**: Glass morphism, neon glows, floating animations
- **Layout**: Single-page with smooth scrolling sections

### 📱 Sections

1. **Hero**: Cinematic introduction with animated background
2. **About**: Professional background and achievements
3. **Skills**: Interactive skill bars with impact metrics
4. **Projects**: Featured portfolio projects with live demos
5. **Services**: Enterprise service packages with pricing
6. **Contact**: Professional contact form and lead magnets

### 🔧 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
